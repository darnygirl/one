## 📁 ARCHITECTURE

### Clean Structure
```
web/src/
├── components/
│   ├── chat/           # 5 modular components
│   └── ai-tools/       # 4 tool renderers
├── lib/
│   ├── chat/           # 10 utility modules
│   └── ai-tools/       # 8 tools + registry
└── pages/
    ├── chat/           # 2 demo pages
    └── api/            # 2 API endpoints
```

- **Frontend:** Astro 5, React 19, TypeScript
- **Styling:** Tailwind v4, shadcn/ui
- **AI:** OpenRouter API (15+ models)
- **Tools:** 8 integrated APIs
- **State:** React hooks, localStorage
- **Performance:** Optimized rendering, code splitting ready
