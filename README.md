# 🚀 ONE Platform - AI Chat Interface

**Production-ready ChatGPT competitor with 15+ AI models, 8 AI tools, and generative UI.**

## ✨ Features

- ✅ **Centered Prompt UI** - ChatGPT-like interface with smooth transition
- ✅ **15+ AI Models** - Free (Gemini) + Premium (GPT-4, Claude, Llama)
- ✅ **8 Working AI Tools** - Weather, Search, Calculator, Translation, Time, Currency, Formatter, UUID
- ✅ **Generative UI** - Dynamic charts, tables, forms, timelines
- ✅ **Conversation History** - Save, load, export (JSON/Markdown)
- ✅ **Prompt Templates** - Pre-built templates for common tasks
- ✅ **Dark/Light Mode** - Theme switching
- ✅ **Mobile Responsive** - Works on all devices

---

## 🚀 Quick Start

```bash
# Install dependencies
cd web
bun install

# Start dev server
bun run dev

# Open http://localhost:4321/chat
```
